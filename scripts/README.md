# Utility Scripts

Collection of utility scripts for the project.

---

## Scripts

### `analyze_labels.py`
Analyze the dataset structure and label distribution from `sheet.csv`.

**Usage**:
```bash
python scripts/analyze_labels.py
```

**Output**: Prints dataset statistics and label distributions.

---

### `run_hieracascade.sh` / `run_hieracascade.bat`
Quick start scripts for training BinaryCascade.

**Linux/Mac**:
```bash
./scripts/run_hieracascade.sh
```

**Windows**:
```cmd
scripts\run_hieracascade.bat
```

---

### `update_nb_paths.py`
Update paths in notebooks (internal utility).
